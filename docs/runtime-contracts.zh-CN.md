# Umi 运行契约

日期：2026-10-24。本文记录当前实现需维持的约束，不是功能愿望清单；历史v1设计与本文不一致时，以真实源码和当前状态为准。

## 输入、执行身份与历史

- commandId绑定用户动作的幂等内容；相同ID不同内容拒绝，不能重复创建输入或副作用。
- conversation/environment/run/turn/attempt/execution/approval/artifact身份分别定位对象，入口验证实际归属。
- 同一environment只有一个活动执行者；generation代次阻止旧执行者提交或派发，不能单凭租约失效认定外部进程已停止。
- 新普通消息、问答回答、明确allow/deny分开。新要求保留原话并在安全边界接纳，不能将“继续”当作模糊批准。
- 事件序号按整数语义处理；原始消息、思考与资料不能因投影折叠被改写或删除。工具调用/结果保持完整配对。
- 持久化会话投影是可重建的派生缓存；按构建、日志身份、位置和完整性核验，失效回退原始事件。不持久化未提交状态，不替代授权与恢复事实；永久删除会话同时清除缓存。

- 兼容DB10格式：其model.delta正文无损分块，每条成员仍有原身份行；身份、幂等键、顺序、时间及内容可还原。坏块拒绝而非跳过，删除时展开引用并原子移除正文与身份行；当前新写入采用下述DB12范围布局。

- DB11仅增加非唯一查询索引，不改变1–10迁移指纹、正文或资料身份；任务许可绑定最新接收用户输入，包含尚未应用的新要求，不能因查询优化恢复旧许可。

- DB12只对新模型流批次减少物理身份行；宿主批次UUID/偏移分配成员身份，首行与范围/完整块同事务。控制事件独立，原SQL消息外键保持；逻辑读取/重连/幂等/缓存核验均还原原成员，坏块或缺口失败，不自动重写旧历史或迁移批准。整组删除级联移除范围并展开正文核对资料引用。

- 非活动会话投影按最近使用保留，默认16条与64MiB序列化估计预算；当前单个超大状态仍可用，活动任务/重建不逐出，不承诺进程硬上限。淘汰只丢可重建缓存，原始历史保留；派生写入失败不改变已提交业务结果，流片段不逐片写完整投影。

原始事实与派生缓存的完整性约束属于应用内部一致性。当前没有对同用户已获准恶意原生命令的OS抗篡改保证；控制目录排除只约束经过检查的结构化入口。实际事实链与无沙箱边界见[收口记录](records/20261024-facts-and-unsandboxed-boundaries.zh-CN.md)。

## 模型请求与结束

- 请求按当前未派发配置冻结并保存，网络重试使用真实尝试身份。完整合法响应后才提交可执行工具；残缺参数不执行。
- 工具参数根是object，输入校验与条件说明需要一致；解析错误提供有界字段原因，不回显全部参数或密钥。
- 已有实际输出后的流中断不无条件原样重试。无活动超时、模型finish_reason、用户停止和语义完成是不同事实。
- 不按累计网络协议外壳大小、逐字重复思考或成功工具调用次数取消正常任务；原始分片无损压缩，思考重复只记诊断。同输入/同请求的已知相同失败先反馈提醒，之后仍失败才受阻收尾。
- 思考强度与输出容量分开，默认单次预留65,536，必要时按剩余上下文下调；不删除原话换容量。
- 默认没有24轮隐藏上限。普通设置移除输出预算输入，仅保留旧版显式限制的展示/取消；兼容输出预算按run累计实际输出及付费维护；恢复不清零，缺usage不填0，不声称总费用已被限制。
- 完整stop仅含思考、无正文或工具调用时，仅补一次有具体宿主事实的异常续作；依据持久响应绑定最新已应用原话，停止、新输入和未知效果优先。正常正文不受关键词重答检查，残缺调用或思考标记不执行。
- 没有有效最终答复的异常/停止/恢复路径保存本地执行说明；说明不能伪造模型响应或确认用户目标完成。存储失败必须诚实保留失败边界。

## 文件已见版本与直接编辑

- 新工作区使用用户明确签发的直接读改授权；目录绑定不可变，模型不指定物理根或自行签发授权。prepare与实际修改前复核权限、范围、根和路径身份。发现、stat、search、预览和历史笔记不授予新权限。
- 授权按workspace保存，跨run、重启和该工作区新会话复用，直到撤销或最后会话永久删除；归档/停止不撤销。根身份变化拒绝继续，重新选定新对象需明确授权。撤销事实持久化并进入实时批次；旧批准和排队写入不能复活授权，已完成写入不会被假称撤销。
- write_file/edit_file/delete_file/restore_file_version的每次非no-op结构化源修改先保存原字节及预期字节/不存在状态、原定位与意图，再修改并保存回执；按内容去重，不自动丢弃有引用的历史。恢复核对后态和当前身份；自然语言恢复可沿同路径已核验写入链跨多轮撤销，旧恢复API继续沿原恢复关系处理。原恢复结果仍一致时重复请求不再写入，遇用户后续修改或外部替换拒绝整文件覆盖。备份失败不先写源文件；命令及外部修改不保证可恢复。
- read_file行模式与字节起点不混用；lineCount单独使用从第1行读取。续页使用返回的UTF-8起点与版本。
- 成功且反馈给模型的read_file范围可作为原文依据；成功write_file的模型自写正文可直接作为已见内容；局部编辑仅传播已见范围和新参数字节。
- 宿主可从同环境、同文件不可变事实自动取得依据，不要求模型传回回执/哈希；显式提供的兼容参数仍严格验证。
- 内容或对象身份变化、未读/隐藏范围、零命中、歧义、重叠及非法编码均不得悄悄覆盖。批量定位针对同一原版本，失败整批不写。
- create只新建；replace需完整已见范围；精确编辑保留原BOM/换行和无关字节。派发和落盘前复核冻结对象，恢复只观察原冻结目标。
- 内部knownRanges是冻结计划中的可选派生范围，不是新read_file、用户消息或授权。

- recycle_file走独立批准及系统回收站，不进入上述file_changes版本备份；不能承诺由自然语言版本工具撤销回收站操作。

### 自然语言文件恢复

- 当前会话的版本按同一run/同一文件合并，分页查保留历史；不承诺跨会话或命令副作用恢复。“上一版”与多文件范围不明确时先定位或澄清。恢复是整文件回到所选记录之前，可能连带回退同工作区其他会话对该文件的连续后续Umi修改；应说明整体范围。其他会话下一次读写重新核验真实文件，旧读取依据不能静默覆盖。
- list_file_versions只列当前授权路径已核验记录；read_file_version是历史备份，不冒充当前文件已见内容。恢复选择restoreChangeId，在prepare/执行前重查权限、身份、字节与连续版本关系。
- 人工后改先比较历史与当前内容，可通过既有edit_file保留无关后改；重叠冲突不自动裁决。恢复新建文件涉及删除时仍具体批准。恢复本身写前备份并留新记录，未知结果只核验原执行，不重派。

## 授权、宿主命令与恢复

- 批准绑定具体请求、内容、目标、环境与版本；拒绝不能换名绕过。源交付和独立导出不继承副本编辑批准。
- 新外部直接访问由request_directory_access签发明确工作区授权；普通编辑不包含host-code、安装、外发或发布。Umi控制数据从结构化入口排除，项目配置/Skill/模型不能提高宿主授权。旧外部副本仍按原run范围核验，unavailableMounts仅提示历史位置，不升级权限。
- 副作用派发前持久化意图与上下文。dispatched/unknown结果不明确时先核验原执行，不以再次执行证明原执行。
- Shell/cwd/Job与Electron renderer隔离均不是宿主OS文件/网络沙箱。auto仅复用用户明确签发的本任务具体开发命令许可，Docker/WSL信息也不是自动授权。
- 命令核验具体程序、参数/脚本、cwd根与环境；输出和退出回执如实区分停止、失败、未知及成功。read_process_output的find仅字面定位本会话原执行归档并返回范围，不重跑命令；未命中不代表未归档内容也没有匹配。脱敏归档超限必须标不完整。
- 重复保护以真实可核验版本变化处理必要读改/复测，不以调用ID、环境修订或模型声明证明进展。

### 任务命令许可

- 自动模式首次宿主命令仍询问；只有支持的具体开发命令允许用户选择task范围。允许本次和旧批准不会升级。完整候选及匹配字段见[实现契约](records/20261023-task-command-permissions-and-deletion.zh-CN.md)。
- 许可绑定实例、run、租约代次、最新用户输入、设置修订和目录授权。停止/恢复、新输入、切回询问再开启、重启或程序/cwd/授权变化后失效；每次有新执行身份、真实来源和持久派发事实。
- 来源记录失败不决定allow、不派发；未知效果仍先核验原执行。派发与原生释放前都重新核对，不因UI已隐藏卡片或模型声称安全跳过检查。用户已信任命令可执行任务中变化的项目代码，这不构成OS文件/网络限制。

## 交付、成果与任务证据

- 新直接编辑不需要ChangeSet交付。旧ChangeSet只冻结选定当前字节，不执行编译或构建；来源当前版本冲突不覆盖。交付/恢复回执只确认冻结字节的写回或满足，不能证明源码修复已进入成品或运行成功。逐项回执与最终用户目标的完成判断分开。
- 独立成果先冻结，导出对具体目标独占创建且不覆盖；未知导出先inspect，不重导或换名绕过拒绝。
- 系统打开请求被接收，不证明网页首帧、动画、排版或交互可用。内置静态预览不执行脚本。
- 任务检查点、要求索引和工作笔记是按需辅助，不是操作、续作或交付前置；不因未完成记录强制模型重答。已有记录和结束评估保留，verified关联真实工具证据，review不由模型自报通过；新更正不能默默降低或删除验收。用户停止执行不等于取消目标。
- 模型最终正文仍可能语义不充分，现有结构化检查不构成通用完成证明。

## 联网与外传现状

- 网页搜索/抓取沿现行自动策略，查询词和URL可包含已读内容；公网上目标检查不构成通用外传内容授权。配置模型会收到进入请求的内容。显式发送/发布工具的批准也不能被描述为覆盖所有联网外传。
- 独立外传边界尚待设计；不以域名检查、模型提示或普通目录授权宣称具备OS网络隔离。本次保持现有联网行为。

## 资料、扩展与桌面

- 摘录、索引和摘要必须保留来源与范围，不能称未读内容已完整阅读；原资料能按现有工具追回。
- 附件按会话/已发送已应用来源读取，草稿与跨会话资料拒绝。Office提取不等于渲染/重算，图片容器观察不等于完整视觉验收。
- Skill按需读取/使用，来源、导入实例与本地字节分开；导入确认不执行脚本或放宽宿主权限。list_skills可按query搜索已启用名称/说明；read_skill默认8192、最多64000字节，按nextStartByte和版本续读。设置可在导入/启用前分页查看完整SKILL.md，预览不代表启用，正文或冻结包变化拒绝混页。开关配置读写统一64KiB，写前检查避免保存不可读配置。
- 顶部权限/修改卡片不再作为恢复入口，工作区菜单保留目录授权查看/撤销。正文文件链接只解析已知mount，走现有预览权限检查；未知file URL不交系统打开。Markdown渲染修正不改写原消息或复制字节，不执行原始HTML。
- renderer只调用固定用户API；桌面事件订阅、预览与管理命令不能开放任意SQL/文件/Shell。
- delete_workspace仅接收工作区身份及明确confirm，事务删除其全部会话、授权和无其他引用的资料；不删用户源文件/导出文件。任一会话仍活动、等待批准或存在未决效果（含文件恢复意图）时整组拒绝；事务失败全组回滚，托管目录提交后按原身份清理，失败保留重试项。
- 核心、桌面与扩展沿同一个Agent循环，不增加隐藏执行者。原始证据、配置、个人数据库、学习/对照报告和生成产物不进入源码提交。

工作区删除完成凭据与整组数据库删除同事务保存，仅保留身份与时间。管理响应超时不代表删除失败；固定只读状态入口核对原工作区。源文件不删除，托管目录清理失败仍为pending。凭据不构成文件授权或恢复内容。
