# Umi 0.3.0 · Windows x64

发布日期：2026-10-24。此版将普通文件任务改为直接编辑明确授权的目录，加入自然语言版本恢复、工作区管理、任务内具体命令许可，以及DB12流片段与历史缓存改进。0.x仍处于开发阶段；正式Release不代表所有功能开放或具备OS沙箱。

## 相对0.2.1的主要变化

- 选择目录即明确授权在其中直接读改，源文件会在任务执行中变化。授权按工作区跨run/重启复用，可在工作区菜单撤销；撤销阻止后续访问并请求停止，不回退已完成修改。
- 普通任务无需先复制整个项目、冻结ChangeSet、再批准交付。写前备份、diff、文件身份与已见版本检查保留；源文件变动时拒绝悄悄覆盖。旧副本、未交付成果和冻结批准仍按原语义处理。
- 可说“帮我回到上一版”，由模型定位本会话保留的文件版本。恢复是整文件回到所选记录，可能连带回退同路径其他会话的后续Umi修改；其他会话旧读取依据会被拒绝。外部后改冲突需先比较，命令/网络副作用不保证可恢复。
- 自动模式首版允许用户选择本任务重复运行已具体批准的开发命令；每次有独立执行身份和批准来源。首次及不支持/高危操作仍询问，停止、新输入、撤销、设置/对象变化和重启使旧许可失效。脚本代码可能变化，许可不构成OS目录或网络隔离。
- 工作区菜单支持整组原子删除与完成状态核对，保留真实源文件和导出文件。目录授权管理移至工作区菜单，顶部权限/修改卡片移除；修复蓝色文件预览、中文重点与表格展示。
- 改进启动与长历史加载：可重建投影、分段重建、明确加载/错误状态及非活动缓存软预算。DB12新模型片段按批归档并完整还原逻辑历史，批准、派发和文件修改等控制事件仍独立保存。

## 升级与数据兼容

1. 更新前用“应用 → 退出 Umi”完整退出旧实例；关闭窗口只是隐藏。备份完整用户数据目录，再更新程序或解压新便携包。不要把项目文件混放进程序安装目录。
2. 数据库从DB7增量升级至DB12，保留旧会话、原始历史、旧批准、旧副本和未交付成果。不会自动写回源文件、提升旧批准、清空测试数据或压缩重写旧事件。
3. 旧程序不能直接打开DB12。需要退回旧版时使用升级前的独立完整备份，不能把旧程序直接指向已升级库。
4. 安装包与便携包均使用同一构建指纹；本版没有自动更新。安装/解压新程序不会替你处理所有既有安装位置。

## 保留的边界

宿主命令没有OS文件/网络沙箱；获准代码仍可访问当前用户能访问的其它文件与网络。结构化控制目录排除和事实日志完整性不保证抵抗同用户恶意原生代码篡改。

网页搜索/抓取保持当前自动策略，查询词/URL可能携带已读内容；配置模型也会收到请求内容。通用外传边界尚未实现。

恢复不覆盖任意命令、网络或外部应用效果；巨大活动会话、长期压力、语义任务完成仍有验证缺口。HTML仅静态预览，无通用浏览器视觉验收；没有computer use、第二Agent或全访问模式。

本轮不调用付费模型API，不执行实际安装、升级或卸载，不改默认会话或Windows设置。安装器载荷及便携exe验证不替代上述交互验收。无代码签名；下载后核对校验文件。
