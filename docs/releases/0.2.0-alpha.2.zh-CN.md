# Umi 0.2.0-alpha.2 · Windows x64

发布日期：2026-10-18。实验性预发布，包含0.2.0-alpha.1之后的模型、网页研究、会话管理与文件预览更新。

- [完整便携包](https://github.com/QI-seven33/Umi/releases/download/v0.2.0-alpha.2/Umi-0.2.0-alpha.2-win-x64-portable.zip)

升级前通过“Umi → 退出 Umi”完整退出旧实例，备份需要保留的用户数据；关闭窗口只是隐藏。便携包完整解压后运行Umi.exe，安装版采用当前用户安装。用户数据与安装目录分开。

本版数据库从迁移6升级到7，保留旧迁移与历史记录，统一CLI和桌面就绪版本。旧程序不能当作数据库降级方案；需要退回旧版时使用升级前的数据备份。新增加的永久删除仅在归档页明确确认后执行，清理会话与托管工作资料，保留用户源文件和已交付/导出的文件；没有内建撤销。

## 主要变化

- 模型菜单、输入区和设置显示具体型号DeepSeek-V4.1-Flash-1017、DeepSeek-V4-Pro-0813，实际API路由保持官方ID。
- 搜索改为直连DeepSeek Search，统一工具为search_web，保存完整搜索回执，返回有界来源与摘要。
- 新增DeepSeek Fetch网页正文读取和不可变Markdown快照，提供目录、字面查找与UTF-8连续补读；模型摘录与完整存档分开。
- 归档会话可明确确认永久删除，事务清理引用，固定托管目录删除失败时记录待清理项，重启核验后重试；侧栏准确标为“归档会话”。
- 修复HTML初始空文档与分页反复导航的触发路径，完整正文到达后一次挂载；补充空文件、片段、长文档与多格式真实桌面回归。
- README围绕Umi完整任务流程和核心设计组织，完善使用、贡献、验证与版本边界说明。

## 验证与范围

本轮类型检查与桌面构建通过；全量核心484/484、源码桌面78/78、实际便携Umi.exe桌面78/78、实际便携预览专项34/34通过。全部使用独立测试数据和模型替身。

目标环境为Windows 10/11 x64；本机验收为Windows 11（10.0.22631）、Node.js 24.21.0、Electron 44.5.1。GitHub托管CI按工作流指定的离线协议/文件IO/界面逻辑子集运行，不代替本机原生进程桥与桌面交互检查。

## 已知问题与执行边界

A-01启动写者标记恢复与A-02部分TASK_LIMIT正文仍待处理。HTML问题已修正本轮复现的触发路径；静态预览不运行脚本或加载远程资源，不承诺任意网页与浏览器完全一致。PDF/Office完整内置解析尚未接入。

宿主命令没有操作系统级文件/网络沙箱；工作目录、工作副本及Windows Job不构成这种隔离。自动免批准、通用skill/插件加载及任务内宿主信任仍待设计。日志与网页存档有明确上限，网页提取完整性取决于提供商。系统打开回执只证明请求被接收。

安装器未代码签名，未配置自动更新。本次不修改用户默认会话数据库、不调用真实模型API。完整限制见[已知问题](../known-issues.zh-CN.md)。
