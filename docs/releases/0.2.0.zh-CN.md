# Umi 0.2.0 · Windows x64

发布日期：2026-10-18。本版集中整理桌面布局、导航状态和窗口背景，沿用现有文件、研究、命令、上下文与交付能力。

版本统一使用三段数字：Umi 0.2.0，Git标签v0.2.0。后续修复版使用0.2.1，较大功能更新使用0.3.0。0.x仍为开发阶段，名称简化不代表已经达到1.0的稳定承诺；旧alpha标签和资产保留。

更新前通过“应用 → 退出 Umi”完整退出，关闭窗口只是隐藏。便携包需完整解压后运行Umi.exe；安装版为当前用户安装。本版数据库仍为版本7，没有新增迁移，不会自动清空会话。

## 主要变化

- 新会话使用居中的“Thus begins the story.”，输入区位于视觉中部；发送首条消息后复用同一输入框并恢复底部布局。
- 窗口移除Mica，浅色外围统一#F9F9F9，深色使用对应纯色；保留原生窗口控制和开发/发行菜单区分。
- 对话主卡片、设置主面板与普通输入框使用柔和静态边缘阴影，聚焦不额外浮起。
- 统一新会话、历史会话和设置导航的圆角、悬停/选中底色及行高；保留维护者选择的浅色#E8EAED。
- 工作区仅悬停时显示背景，当前会话保持选中底色；232px侧栏、按钮占地、面板边缘和设置布局对齐。

## 验证

本次类型检查、构建、核心全量486/486、源码完整桌面85/85及实际便携完整桌面85/85通过。196个运行文件逐项hash一致，安装器内嵌载荷核验与便携ZIP完整性检查通过。公共文档本地链接与待提交文件凭据扫描通过。托管CI只覆盖工作流列出的离线子集，具体提交及结果随发布页记录。

首次桌面检查因旧中文欢迎语断言失败；已保留维护者修改的英文“Thus begins the story.”，将两处断言对齐后重新执行完整桌面验收。失败证据保留，没有放宽布局、节点身份、主题或交互检查。

安装器与完整便携ZIP从同一已验收构建生成，发布前核对实际安装载荷、Umi.exe、ZIP完整性及SHA-256。不把载荷校验当作真实安装/卸载交互验收；本轮没有在默认会话库操作或调用真实模型API。

## 保留的边界

A-01启动写者标记恢复、A-02部分TASK_LIMIT正文仍待处理。宿主命令没有操作系统级文件/网络沙箱；HTML为静态预览；通用skill/插件加载与自动免批准仍未接入。
