# Umi 0.3.2 · Windows x64

版本日期：2026-11-11。本说明对应v0.3.2；资产以GitHub Release为准。发布不会自动更新本机安装。

本版把此前已默认采用的授权目录直接编辑收口为唯一普通文件执行链，删除仍为旧会话保留的物化、ChangeSet交付及交付打开实现。独立成果/导出、备份、冲突核验、恢复、具体命令许可和DB12完整历史保持。

## 主要变化

- 删除request_resource、build_changeset、deliver_changeset、open_delivered_file及应用、CLI/IPC、冻结预览、专用卡片与仓储执行入口；完整桌面工具表从52项变为48项。
- write/edit/delete统一经过真实目录的授权与写前备份。目录授权、已见范围、版本/身份核验、自然语言恢复和独立成果导出继续保留；旧批准不会升级为目录授权。
- 旧副本会话停止发送、恢复与批准执行；既有迁移、历史事件解码及删除依赖继续保留，不自动复制、写回或清空旧数据。
- 退役旧流程专用测试/夹具，通用文件、命令、预检和删除用例迁移到真实直改链路。构建前清理失去源码的旧JS/声明输出，防止已删模块仍被加载或打包；遇目录链接拒绝清理。
- 同步工具提示、内置Skill和预检说明。document_open任务证据改为绑定open_file的真实目标及版本，后续文件变化会使旧证据退回待审，不重新打开。

## 升级与兼容

- package 0.3.2，DB12，umi-persona-26。不新增数据库迁移，不自动重写或删除旧记录。
- 0.3.0/0.3.1的直改会话、授权、备份及恢复继续使用。0.2.1等旧副本会话可读取历史并按既有规则删除；不能继续旧执行，需明确选择目录新建会话。未知副作用仍可能阻止删除，不能假称未执行。
- 更新前通过“应用→退出Umi”完整退出旧实例，备份完整用户数据目录。保留旧Release和标签，不覆盖既有资产。
