# Umi 0.2.0-alpha.3 · Windows x64

发布日期：2026-10-18。实验性预发布，本版主要修复 Windows 顶栏和开发/发行界面的区分。

## 下载与升级

- [Windows 安装版](https://github.com/QI-seven33/Umi/releases/download/v0.2.0-alpha.3/Umi-Setup-0.2.0-alpha.3-x64.exe)
- [完整便携包](https://github.com/QI-seven33/Umi/releases/download/v0.2.0-alpha.3/Umi-0.2.0-alpha.3-win-x64-portable.zip)
- [SHA-256 校验清单](https://github.com/QI-seven33/Umi/releases/download/v0.2.0-alpha.3/SHA256SUMS.txt)
- [构建与封装清单](https://github.com/QI-seven33/Umi/releases/download/v0.2.0-alpha.3/umi-windows-release.json)

先通过菜单完整退出旧实例：alpha.2 及更早版本使用“Umi → 退出 Umi”，本版使用“应用 → 退出 Umi”。关闭窗口只是隐藏。便携包需完整解压后运行 Umi.exe，安装器采用当前用户安装。

本版沿用 alpha.2 的数据库版本7，没有新增迁移。升级不会自动清空会话；安装器卸载保留用户数据。升级前可备份需保留的数据，安装目录与用户数据目录分开。

## 主要变化

- 将原生标题/菜单与页内顶部控制合并为40px紧凑顶栏，移除界面左上角产品图标，保留 Windows 原生最小化、最大化/还原和关闭按钮。
- 发行构建只显示“应用 / 编辑”，禁用开发者工具；开发版额外显示“开发”。主进程根据 app.isPackaged 判断模式，并拒绝发行界面伪造的开发菜单请求。
- “应用”提供关于与完整退出，“编辑”沿用原生撤销、重做、剪切、复制、粘贴、全选。设置页也保留顶栏入口。
- 修复侧栏展开按钮常驻灰底，以及原生标题按钮固定背景色在 Mica 材质上形成的灰色矩形；悬停采用轻微透明叠色，不增加投影。
- 补充固定菜单参数校验、原生菜单弹出/关闭、浅深主题和窗口状态的真实桌面检查。悬停颜色验收等待过渡结束，保留原有对比度要求。

## 验证与发行范围

本轮在 Windows 11、Node.js 24.21.0、Electron 44.5.1 上重跑类型检查与桌面构建，核心全量486/486、源码桌面83/83、实际便携Umi.exe桌面83/83通过。新版本exe的ProductVersion/FileVersion均为0.2.0-alpha.3。测试使用独立数据和离线模型桩，不修改默认会话库或调用付费模型。

安装器与便携包从同一构建生成。发行脚本在公开前解出安装器实际载荷，逐项校验195个运行文件及 Umi.exe，检查 ZIP 完整性、文件大小和 SHA-256；远端资产也需与本地摘要一致。未额外执行真实安装/卸载，不把载荷一致性当作安装界面、注册表或快捷方式的专项验收。

原生框架截图包含三个窗口按钮；DWM/Mica 壁纸材质不包含在窗口捕获中，透明区域可能在图片查看器显示为黑色，不代表实际应用变黑，也不据此宣称完整壁纸视觉已验收。实现与学习入口见[顶栏说明](../desktop-titlebar-20261018.zh-CN.md)。

## 已知限制
