# Umi 0.3.3 · Windows x64

版本日期：2026-11-22。本说明对应v0.3.3；下载资产以GitHub Release为准，发布不会自动更新本机安装。

本版增加已发送用户消息的原位编辑，补齐后台托盘，并修正目录授权的当前可用状态展示。普通文件任务继续使用授权目录直接编辑，保留备份、版本冲突检查和自然语言恢复。

## 主要变化

- 编辑用户消息后从该处重新继续，不提供版本树；后续旧聊天退出当前视图，文件、命令效果和原始执行事实保留。附件正文不编辑，为新消息复制身份和归属。
- 修订先停止任务并结算，未知效果阻止提交；旧摘要、笔记、任务与命令许可不沿用。历史执行可分页核验，退出上下文的旧读取不再充当当前文件已见依据，排队输入不会抢先恢复旧任务。
- 编辑区采用一体式浅蓝气泡，文字区域透明无边框，提示和按钮同层；紧凑思考点阵缩小，移除只填固定提示语的重新组织回答入口，保留复制、赞踩和引用。
- 工作区保留跨会话授权，当前列表显示可用项，失效/已撤销项进入折叠历史；显示单文件实际路径，刷新或回到窗口时观察当前可用性。不会自动删除历史、寻找新路径或重新授权，实际文件入口继续独立校验。
- 后台模式持有系统托盘，可打开或退出，语言与关闭偏好同步；托盘不可用时关闭直接退出。关闭即退出选项保留，不修改Windows通知区偏好。

## 升级与兼容

- package 0.3.3，DB13，umi-persona-26。DB13只追加消息修订格式与索引，DB1–12的历史和迁移指纹不改写，不自动删除测试或用户历史。
- 升级前完整退出Umi并备份完整用户数据目录。旧程序不能打开已升级的DB13；如需降回旧版，应使用升级前的数据备份。
- 编辑消息不会回退磁盘内容、进程、联网或外部服务效果；需要恢复文件时继续使用已有文件版本恢复功能。没有安全擦除或版本树。
- 旧物化副本会话仍只读历史或删除，不能恢复旧执行，也不会自动提高权限或写回。

## 保留的限制

原生命令没有OS文件或网络沙箱；项目目录检查、具体批准与Job进程管理不构成这种隔离。网页工具独立外传边界仍未完成。本版不宣称解决旧大库删除延迟、长期内存压力或提高真实模型任务成功率。

Markdown预览组合断言此前曾间歇失败，独立复查通过，根因未定位，见[已知问题](../known-issues.zh-CN.md)。本轮使用隔离库和离线模型，不安装/升级/卸载程序，不调用付费模型或操作默认会话库。托盘检查不等于人工点击Windows通知区验收，安装器载荷一致不等于实际安装体验通过。安装包未代码签名，没有自动更新。
