# Umi 0.3.1 · Windows x64

版本日期：2026-10-25。本说明对应 v0.3.1；安装器、便携包与校验文件以 GitHub Release 实际资产为准。发布不会自动更新本机既有安装。

本版集中改善桌面设置、权限提示与会话管理，修复文件引用误识别，并为授权目录内的文档增加独立批准的系统打开入口。沿用 0.3.0 的直接编辑、文件版本恢复、任务内具体命令许可和 DB12 历史格式。

## 主要变化

### 界面与会话管理

- 调整设置、权限、工作区目录授权与归档界面的布局和间距，统一柔和圆角、蓝色开关和中性色层次，减少重复文案、装饰边框与投影。
- 权限请求先显示简要操作，完整原操作描述可展开查看；允许本次、任务内复用与拒绝仍是不同决定，批准范围不变。
- 新增简体中文与 English 界面切换，独立保存设备偏好；不改写 Agent 回复、用户消息、历史标题、文件内容或模型语言设置。Skill 正文、原始诊断及审计详情保留原文。
- 会话菜单支持重命名。工作区标题旁新增搜索按钮，点击后展开标题搜索，再次点击收起并清除过滤；Esc 先清空搜索词，再次按下收起。
- 长会话标题支持悬停或键盘聚焦滚动，并保留完整标题提示；减少动效时不滚动。归档确认更紧凑，长按进度由白色填充为蓝色。
- 技能启用控件统一为蓝色圆角开关；移除聊天输入区内部多余的矩形焦点框；补齐空预览侧栏顶部的水平分隔线。

### 设备偏好与存储

- 关闭窗口可选择后台继续运行或完整退出，默认保持后台继续；完整退出沿用既有任务关闭流程。
- 支持减少动效。存储页展示应用数据、会话资料、默认导出与程序位置，并提供固定位置的复制/打开入口。
- 可选择默认导出目录，仅影响另存为的初始位置；具体导出目标仍按原规则批准，不移动既有文件。会话数据与安装目录仅展示，不支持运行中迁移。

### 文件引用与系统打开

- 文件预览链接先核验授权、范围、身份和文件存在性。命令、程序名、目录、不存在的文件及同名歧义不再仅因外形像路径而显示为可预览链接。
- 子目录文件的简写可从当前根和本会话近期成功文件操作记录定位；查询按批去重并限制范围，点击时仍重新核验，不进行全盘扫描。
- 直接编辑环境新增独立批准的 open_file，通过固定系统文档打开通道调用默认应用，减少普通打开任务依赖命令子进程的情况。
- 补齐命令环境中三项 ProgramFiles 类标准路径变量，减少安装位置误报；继续过滤密钥及非白名单环境变量。

## 升级与兼容

- 从 0.3.0 升级，数据库格式仍为 DB12，提示版本仍为 umi-persona-25；本版不新增数据库格式迁移，不自动清空或转换旧历史。
- 旧副本、冻结批准、直接编辑授权和任务内命令许可保持既有语义。界面简化和设备偏好不授予额外命令、外发或发布权限。
- 更新前通过“应用 → 退出 Umi”完整退出旧实例，并备份完整用户数据目录。安装目录不要混放项目或个人文件。
- 从 0.2.1 等更早版本升级，仍需遵循 [0.3.0 数据升级说明](0.3.0.zh-CN.md#升级与数据兼容)。

## 保留的限制

- 宿主命令仍没有 OS 文件或网络沙箱。工作区授权和具体操作批准不等于操作系统隔离。
- 网页搜索/抓取沿用现有自动策略，通用外传内容授权边界尚未完成。
- 系统打开回执仅证明系统接收请求，不保证浏览器持续运行、页面渲染正确或 HTTP 服务持久存在；普通命令的 Job 清理策略不变。
- 文件预览沿用既有格式与容量限制。文件简写只使用有界来源，不保证找到任意文件；外部改动不持续监听，点击仍重新核验。
- 本版不承诺解决旧大库删除延迟、真实模型任务速度或长期内存问题；DB12 不自动重写旧记录。
- 没有新增全访问模式、开机启动或自动更新。安装包仍未代码签名。
