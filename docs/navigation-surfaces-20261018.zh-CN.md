## 主题变量与样式入口

入口：[surface.css](../apps/desktop/renderer/src/styles/surface.css) 的“导航的状态靠平面底色”段落：

- --nav-hover：未选中会话、新会话和设置导航的悬停底色。
- --nav-selected：当前会话和设置分类的选中底色。
- --nav-selected-border：选中描边，当前透明。
- 文件顶部 --control-radius：导航圆角，当前10px；--sidebar-row-height：行高，当前34px。

此次保留历史会话原先实际生效的深浅：浅色两项均 #e5e8e8，深色均 #ffffff1a。此前 .left-sidebar 将 --nav-hover 绑定到 --nav-selected，单改根变量可能看不到变化；该局部覆盖已移除，现在两项可独立调整。

候选调色未纳入此阶段交付，本文保留实际采用值及变量入口。

源码调整后，关闭正在运行的本地便携Umi，再运行 npm run package:desktop 可重新构建并同步便携目录；该命令不生成Setup安装器。仅运行 build:desktop 不会同步便携目录。
