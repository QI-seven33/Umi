# 流片段范围存储与会话投影保留

日期：2026-10-24。未发布开发源码，package仍0.2.1、persona-25，数据库格式12；不包含默认库操作、打包、安装或发布。

## 问题与实现范围

大量`model.delta`代表模型传输片段，不能把几十万条记录解释为几十万次工具执行。但每片都承担完整事件行、JSON与多份唯一索引的成本并不合理。DB10只压缩正文；DB12进一步减少新批次的物理身份行，同时保留全部逻辑事件。

- 保持唯一Agent循环、原事件协议与纯归约器。批准、工具派发、文件修改及其他控制事件继续独立持久化，原有消息外键仍指向控制事件。
- `event_ranges`新增批次范围，与`event_blocks`正文、首片`events`行、会话序号及投影在同一事务提交。2–64片且正文不超过2MiB时归档；单片或大正文继续标量保存，不新增文本拒绝限制，也不延长原刷新周期。
- 首片保留SQL索引；其余片段身份使用宿主批次UUID与偏移派生。普通追加入口不能新占用该命名空间；旧标量幂等键优先兼容。读回原成员仍核对幂等内容与归属，不能用同键不同内容推进历史。
- 新表的不可修改与范围冲突触发器阻止覆盖已占序号；批次主键约束全局唯一，原有控制事件唯一约束保持。块解码校验摘要、长度、Schema、身份、归属及连续序号。
- 逻辑读取支持任意批次内游标、64位序号与分页；中间缺口或损坏明确失败。冷重建、异步重建、投影缓存尾部核验和列表更新时间均使用新布局。生命周期、输入及消息SQL只消费仍独立保存的控制事件。
- 删除继续整组数据库原子提交。首行删除同事务级联删除范围，正文块沿原清理顺序移除；资料引用扫描继续展开完整块，保留跨会话共享资料。源文件和已导出文件保留。
- 迁移12只增加格式表与约束，不重写旧事件、正文块、批准或1–11迁移指纹。旧程序不能直接读取DB12；默认库转换或清理不属于本次操作。

## 会话投影的内存保留

原`states`会随打开过的会话累积。现按最近使用顺序保留非活动投影，默认16条、64MiB序列化估计预算；活动任务和正在重建的会话固定保留。当前一条超大非活动投影仍可用，故这不是进程硬内存上限。

淘汰只丢弃可重建状态与缓存记账，不删除原始历史。派生缓存失败不改变业务提交结果；回滚后清掉内存记账，避免把未提交状态当作已保存。模型流提交不逐片序列化整份投影。验证包含反复切换、活动任务结束、派生写失败及异步重建期间较新提交。

## 实际任务对照

同一离线DeepSeek传输经真实适配器、Agent、SQLite与文件工具，两次均生成50,489字节文件，只有一次成功写入；50,567个模型片段、50,605个逻辑事件均保留，重启后完整逻辑事件逐字段相同。删除目标工作区后文件仍在，另一工作区仍可读取。

对照进程仅替换存储写入方法复现DB10逐身份行布局；不是运行完整旧发行版。每种布局只测一次，不是统计分布或真实模型提速结论。

| 同任务布局 | DB10正文块/逐片身份行 | DB12范围布局 |
| --- | ---: | ---: |
| 逻辑事件 | 50,605 | 50,605 |
| events物理行 | 50,605 | 830 |
| 正文块 / 范围行 | 791 / 0 | 791 / 791 |
| 上述三表及其主键/唯一索引页 | 30,228,480字节 | 2,568,192字节 |
| headless任务 | 10.62秒 | 10.17秒 |
| 保留另一工作区时整组删除 | 1.45秒 | 0.86秒 |

所列页占用减少约91.5%，包括块和范围在内的物理记录从51,396条降到2,412条。逻辑事件仍可还原，不能以物理`count(*)`代替逻辑事件数。这不是整个数据库文件大小，也不能证明旧800MB库变快。当前单次任务耗时差异不足以宣称普遍执行提速。

## 验证与剩余范围

专题验证包含旧标量/DB10混读、批次内各位置续读、首尾幂等重取、64位序号、缓存尾部落在批次内、坏块/缺失范围、写入故障、真实进程提交前后硬退出、共享资料及整组删除回滚。迁移样本先结束模型尝试，避免把正常启动恢复新增事实误判为历史被改写。

最终源码构建通过，完整核心781/781通过；真实renderer→preload→broker→worker→SQLite的隔离Electron110项通过。旧约800MB隔离副本的430,090条事件逐字段及原payload字节一致，242条消息与1,689条资料逐字段一致，外键/完整性通过；未转换旧历史。`git diff --check`通过。不以回归数量代替上述文件任务的真实结果。

旧大库未压缩重写，仍有逐事件行、全局资料引用扫描、完整事务落盘和WAL检查点成本；不宣布旧删除等待已根治。请求/context资料跨轮重复、单个活动超大投影及长期压力仍有优化空间。没有自动历史TTL、后台分批永久删除、Git快照或新执行模式。

当前无宿主OS文件/网络沙箱；普通编辑不授予命令、发送或发布权限。网页工具策略保持原状，独立外传边界尚未实现。存储改版既不扩大权限，也不意味着获得更强隔离或更高模型智力。
