# 桌面界面与设备偏好

日期：2026-10-25。适用未发布源码；package仍为0.3.0、DB12、persona-25。本次没有打包、安装、推送或发布，没有使用付费模型，也未操作默认会话库。

后续版本归属：本记录实现纳入0.3.1，本版重新验证与交付状态见[0.3.1版本说明](../releases/0.3.1.zh-CN.md)。以下版本、日期、测试结果及“未发布”描述保留为当时记录。

## 可见变化

- 权限卡片使用更柔和的按钮、紧凑间距与简要程序/工作目录；完整原操作描述放在可展开详情中。允许本次、任务内复用和拒绝仍为不同决定；旧交付卡片继续显示冻结范围。
- 工作区目录权限改为统一模态对话框：显示工作区名、路径、权限状态与撤销按钮，减少长段说明；授权生命周期与撤销业务不变。
- 设置保留原232px侧栏、原配色、统一外缘与欢迎语，新增存储与关于分类，分组靠底色与留白组织；移除新增浮层投影及嵌套装饰边框。选择器、开关、输入框与技能导入均使用统一样式，包含键盘与焦点状态。
- 全局简体中文/English界面语言即时切换并持久化，只处理界面自有文字。用户原话、Agent正文/思考、会话历史标题、文件内容、路径、Skill原文与后端原始诊断不翻译。
- 会话菜单支持重命名；侧栏支持标题搜索、无结果状态、清空与Esc清空；长标题在悬停/键盘焦点时滚动，离开恢复，完整标题也保留提示。系统或应用减少动效时不滚动。
- 归档确认卡片与按钮缩小，长按进度由白底填充蓝色；短按不执行。空文件预览栏也保留与聊天标题同高的横线。
- 点击窗口关闭可选择后台继续或完整退出，默认保持后台继续。减少动效可配置。存储页显示应用数据、会话资料、默认导出与程序位置，可复制/打开；导出目录可通过系统选择器更改，数据与安装目录只展示。

## 截图反馈后的调整

技能启用控件复用通用设置的蓝色圆角开关，保持原启用/停用入口。只移除聊天输入区内部的矩形焦点轮廓，保留其它控件的键盘焦点反馈。会话搜索默认收起，搜索图标与新建工作区加号同尺寸并排；点击展开并聚焦，再次点击收起并清除过滤。Esc先清空已有词，再次Esc收起并返回图标。

截图反馈后的构建与15项隔离桌面验收通过，实际覆盖技能启停保存/恢复、搜索默认收起与展开定位、Esc及关闭时清除过滤，以及聊天输入区内部无焦点描框。未重新打包、安装或发布。

## 实现入口

| 入口 | 职责 |
| --- | --- |
| `packages/protocol/src/desktop-preferences.ts` | 完整配置默认值、严格增量更新和固定数据位置类别 |
| `apps/desktop/preferences.ts` | 小型设备配置读写，临时文件替换，异常读取不覆盖原文件 |
| `apps/desktop/main.ts` / `preload.ts` | 固定IPC、系统目录选择、固定位置打开和原退出路径 |
| `renderer/src/ui-language.ts` / `ui-translations.ts` | 界面文案及订阅；不接入Agent语言设置 |
| `renderer/src/components/ui/{Select,Dialog,OverflowTitle}.tsx` | 统一选择器、原生模态焦点边界与有界标题滚动 |
| `renderer/src/features/settings/DesktopSettings.tsx` | 设备偏好、存储与应用信息 |
| `renderer/src/features/sidebar/RenameConversationDialog.tsx` / `Sidebar.tsx` | 既有重命名入口、标题筛选与滚动显示 |
| `renderer/src/styles/refinements.css` | 桌面界面最后一层样式，沿用既有令牌与加载顺序 |

表中renderer路径均位于`apps/desktop`下。技术入口与用户界面文案分开，未增加第二Agent、任意IPC、Shell/SQL/文件系统页面入口。

## 必须保持的契约

1. 设备偏好不传播到会话Settings、原始历史、模型请求或权限事实。增量更新不能给缺省字段套默认值；只改关闭行为不能把英文切回中文。开发验收曾实际发现此联动错误，现用无默认值的增量schema修复，并增加保存/重启检查。
2. 目录授权不隐含命令、外发或发布许可。简化卡片不改变批准内容；完整原描述仍可核对。宿主命令仍无OS文件/网络沙箱。
3. 默认导出目录仅影响另存为初始位置，具体目标继续批准；现有文件不迁移、不覆盖。选择器取消不写入偏好。运行中不迁移数据根。
4. 关闭选择退出复用现有核心关闭流程，后台模式保留任务。没有在UI中另起退出或执行链。
5. 重命名只改标题，经既有120字符校验；搜索不删除或重排原始历史。旧名称不会因界面语言改变。

## 验收及限制

使用现有离线模型、新建临时数据目录和真实Electron窗口验收。实际交互覆盖重命名持久化、标题筛选/无结果、长标题真实悬停滚动、选择器键盘打开/Esc、语言刷新恢复、窗口后台隐藏、固定路径信息与非法IPC拒绝，并逐项比较切换前后的会话设置和消息。独立进程检查退出选项经过真实关闭流程退出。浅色、深色和英文存储页已截图检查，后续完整桌面验收还覆盖原批准、拒绝、任务许可、归档、文件预览和工作区撤销/删除。

最终命令结果以`docs/evidence/desktop-runtime.json`、`interface-runtime.json`和`window-close-runtime.json`中的本轮隔离记录为准；这些原始证据不提交Git。构建与自动化测试不代替用户审美确认或长期使用。没有操纵系统目录选择器/资源管理器、默认库、其它应用或真实付费模型；没有安装版关闭交互验收。原始后端诊断和权限详情仍可能为中文，不自动翻译审计原文。
