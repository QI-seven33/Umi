# 查询热路径与整文件恢复契约

日期：2026-10-24。未发布开发源码；package仍0.2.1，DB11，persona25。安装版未更新，没有打包、安装、发布或推送。

## 实现

- 新增迁移11，只增加6个非唯一索引：资料kind/hash、任务许可run与批准身份、复用执行身份、用户消息run、消息turn/role/applied。迁移1–10指纹、旧事件/资料正文和身份不变，不重写旧历史或批准；相同正文的不同资料身份仍可存在。
- 任务许可查找采用固定kind和JSON路径，实际使用表达式索引。最新用户输入改为按真实事件顺序定位单条消息，不再取出整段会话正文；包含尚未应用的新用户要求，并核验所选原话指纹。实例、run、代次、设置、目录授权和具体命令的失效条件保持。
- 文件恢复明确为整体回到所选历史记录之前的完整字节，可以连带回退同工作区其他会话对同文件的连续后续修改。没有增加恢复模式或监听器；其他会话下一次读写仍以真实文件身份/字节核验，旧读取依据不得覆盖，重新读取后可继续。
- 新增索引升级与待应用输入用例，以及贯穿A/B会话的实际文件恢复用例。现有Windows CI子集纳入索引迁移、直改、自然语言恢复、正文块、工作区删除、投影缓存及回复格式测试；本轮未在远端执行CI。
