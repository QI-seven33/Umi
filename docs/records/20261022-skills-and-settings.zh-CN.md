# Skill读取、开关持久化与设置界面

日期：2026-10-22。适用本地0.2.0开发源码，未发布；DB7、persona-22、依赖及48项模型工具不变。本轮不调用真实模型API、不联网获取技能、不操作默认数据库。

## 已确认问题

1. 开关配置只允许读取16KiB，但技能库允许128个本地目录，保存却没有同等检查。隔离旧实现复现：第104个测试技能保存后配置达到16,434字节，刷新出现配置读取错误，已启用的外部技能全部停用。这是读取与写入容量不一致，不是模型失败。
2. 设置页的本地正文和GitHub草稿预览只展示前12,000字节，没有续读入口，用户无法在启用或确认前检查完整SKILL.md。
3. read_skill每次最多4096字节，工具说明还要求沿分页读完；长技能会增加往返，也与按需使用的定位不符。list_skills原来只能顺序翻页。
4. 设置正文和控件普遍12px，常用行为与诊断统计混排；模型连接把所有hasKey都称为系统加密保存，而环境变量密钥也会令hasKey为真。

## 实现

- 开关配置统一64KiB读取/写入边界。写前校验，超限保留原配置；覆盖当前128项容量。正文版本、导入实例与启用绑定不变，外部正文修改后仍需重新启用。
- 设置预览使用固定管理桥，按12,000字节续页，显示已读范围、完整状态和失败重试。支持停用技能和未确认的冻结草稿；UTF-8边界及sourceHash核验避免混页。草稿预览仅接收导入ID和范围，不开放任意路径。导入确认仍绑定planHash。
- read_skill默认8192字节、最多64000字节，256KiB单个文本上限不变。分页是否继续由任务需要决定，不要求读完每个技能。list_skills增加可选query，对完整名称/说明做不区分大小写的字面搜索，然后分页，只返回已启用技能。
- 技能设置增加全部/已启用/未启用筛选、启用数量、目录路径复制。正文预览错误有明确提示与重试入口，不再一直显示正在读取。
- 增加“通用”分类：复用现有浅色/深色/系统主题；发送方式可选Enter或Ctrl/⌘+Enter，保存在设备localStorage，保留输入法防误发。会话用量放入默认折叠的“用量与诊断”。密钥状态改为准确说明应用配置或环境变量来源。
- 沿现有组件调整分组行和字号：主标题22px、分组15px、正文/普通控件14px、主要输入36px。原配色、232px侧栏、统一圆角与边缘保持，没有增加UI库或远程字体。

## 尚未覆盖

本轮没有调用DeepSeek，因此不能把减少分页的机制改进换算成真实提速或成功率提升。没有测试真实GitHub网络、私有仓库、全部第三方技能、Windows所有输入法或手工多显示器操作。

设置页完整预览只针对SKILL.md；包内references/scripts/assets仍通过本地文件或模型按相对路径读取，未增加资源浏览器、技能编辑器或升级市场。脚本不会因安装、预览或启用而运行，真正执行仍走已有命令批准。无沙箱、auto、第二Agent或强制Skill流程变化。
