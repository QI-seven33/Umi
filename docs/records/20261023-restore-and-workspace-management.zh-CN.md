# 连续恢复、授权广播与工作区删除修复（2026-10-23，未发布）

当前源码 package 仍0.2.1、DB9、persona-23。行为仍按0.3.0方向开发；没有打包、安装或发布，本记录不表示安装版已更新。此前直接编辑实现及旧副本兼容继续保留。

## 小契约与具体修复

- 恢复是新的结构化修改。只有当前对象与某条已落库后态一致，并可沿同一路径的已提交恢复关系回到原版本时，才允许连续撤销；不会仅凭内容相同放宽外部替换检查。原修改、恢复修改和关联ID均保留。重复恢复在原恢复结果仍一致时返回原完成事实，不再写入；后来继续撤销到更早版本后，重复请求较新版本会冲突。
- 工作区历史用于核对恢复关系，仍使用原artifact前后字节与去重机制。没有换成Git tree/blob，也不操作用户Git索引。连续恢复已覆盖跨run、重启和同一工作区不同会话；删除某会话会删除其记录，因此不能依赖已经主动删除的关系继续撤销。
- 面板显示修改/恢复记录、时间和明确完成反馈。历史diff仍是原记录的前后差异；“核对当前文件”另外读取真实文件，仅表示内容一致性，不把历史“已记录”当作当前恢复成功。长diff不会把新的操作反馈藏到面板下方。
- 授权先持久化真实grant与环境修订。未加载会话只追加自足权限通知，不为广播强制重建全部历史；按需仍由同一个归约器重放。异步冷重建会消费期间追加的通知尾部。通知与投影缓存不能授予权限，撤销仍由真实grant校验。
- 删除先核验全部选中会话，再在一个事务中按子表依赖整组删除，只进行一次候选/保留资料闭包和外键核验。全部会话都删时跳过即将废弃历史的候选扫描，仍保留其它持久事实引用的资料。共享、间接导出及未知效果保护不放宽。
- 引用扫描避免为普通UUID反复解析相同嵌套JSON，并先检查真实资料ID前缀。Unicode转义或兼容的非UUID资料继续完整解码；对象键、嵌套字符串及跨会话引用继续保留。
- 删除期间把默认小页缓存临时提升到64MiB建议上限，成功或失败后恢复连接原设置。没有关闭外键、降低同步级别或修改Windows设置；该数值不是进程总内存上限。
- 迁移9只增加最小工作区删除完成凭据，保存工作区/会话/环境ID与时间，不保存路径、正文和授权。与数据库删除同事务提交；1–8迁移指纹不改。固定只读API可在响应丢失后查询原工作区，重复删除返回原完成事实。目录清理失败仍记录pending并在下次启动重试。没有完成凭据不能当作成功；界面不会以超时推断失败并重复派发。

唯一Agent循环、命令具体批准、旧副本/未交付成果与冻结目标语义保持。普通文件授权不包含命令/安装/外发/发布。自动执行仍未接入；本轮仅进行独立设计探索，旧auto设置不因此升级。

## 实际验证

完整核心727项通过；真实隔离Electron108项通过。关键实际结果包括A→B→C连续恢复到A、重启后继续、恢复自身可撤销、同字节外部替换和人工后改拒绝、恢复回执幂等、冷通知与重建竞态、整组删除失败完整回滚、跨会话资料保留、DB8→9保留原事件/迁移指纹。Electron实际核对恢复前原字节、面板状态与时间，并在已提交删除后注入响应丢失，确认界面查询完成凭据而非重发删除；原232px侧栏与界面布局保留。

初次完整回归出现5处旧迁移测试硬编码DB8，与实际DB9不符；只更新期望版本，未放宽原数据断言，最终完整重跑通过。上述数量不能证明所有任务与性能都正确。

在约42.8万事件、6条会话的只读一致性备份中进行仪器化测量，全部数据库操作是真实实现，托管目录移除器仅核验并计数：最后工作区删除由此前约78秒降到约8.66秒。另在影子中增加保留工作区，删除原大工作区约22.5秒，保留会话和外键均正确。授权广播由此前约4.85秒降到约23毫秒，强制投影缓存缺失样本约4毫秒。这些是本机样本，未精确复现用户先前7秒，也不等于鼠标到屏幕的端到端延迟或模型提速。

## 剩余范围

大库的非最后工作区删除仍慢，可能超过20秒管理响应超时；现有完成凭据解决结果确认，未消除同步核心阻塞。保留集合仍需扫描历史与资料，不能为提速删除共享/未知证据。后台分段回收需要另外设计一致性、并发和中断语义，本轮没有临时叠加第二清理引擎。

当前恢复仍仅覆盖结构化文件工具，单文件有4MiB上限。多文件修改不具备整体事务，命令/外部修改和资料外发不保证恢复；文件不存在时只能观察不存在事实。路径检查不构成OS隔离或对抗性文件系统CAS。没有新的磁盘配额、自动历史清理或强制验收链。

本轮未操作默认库、用户实际HTML文件、安装版和付费模型，未打包、发布、提交或推送。原始证据、比较资料和私人设计保留本地，不进入公共Git。
